Log Forwarding

Deliver security events to a SIEM or collector over HTTP. Each forwarder profile has its own endpoint, wire format, authentication and event subscription — so a SOC collector can take blocks and file verdicts while a separate analytics endpoint takes activity. Events are batched, retried with backoff and spooled to disk, because HTTP log delivery is lossy at volume.

Content Inspection

                                
Attachments are inspected in the browser, before transmission. File type is resolved from
                                content rather than the filename, containers are opened, the detection catalogue runs over every
                                extracted part, and a risk score selects the response. File bytes never leave the device — the audit
                                record keeps redacted evidence and a content fingerprint only.

                            

                        


                        
                        
Inspection depth

                        

                            

                                
                                
                                
                            

                            

                                Opens archives and Office documents, following nested containers to the configured depth.

Document text extraction

Response actions by risk band

                        
Risk is scored from detection severity, checksum validation, credential presence,
                        compound-identity correlation (DPDP §4), exposure volume and evasion signals. Credential material and
                        bulk personal data at reportable scale set a mandatory Critical floor.

Traversal budget

                        
Bounds every inspection so a malformed or deliberately hostile archive degrades to a
                        partial verdict instead of stalling the page. Exceeding a bound marks the report partial; findings
                        already made are still enforced.
